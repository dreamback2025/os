# 多道程序设计技术演示系统

这是一个基于C语言的多道程序设计技术演示系统，实现了固定分区分配存储管理和进程调度功能。

## 功能特点

### 1. 固定分区分配存储管理系统
- 实现了内存分区的分配与回收
- 支持首次适应算法和最佳适应算法
- 提供内存紧凑功能
- 实时显示内存分配状态

### 2. 进程管理系统
- 定义了进程控制块（PCB）数据结构
- 实现了进程状态管理（新建、就绪、运行、等待、终止）
- 支持自动和手动两种进程创建方式
- 实时显示进程执行情况

### 3. 进程调度系统
- 实现了时间片轮转（Round Robin）调度算法
- 实现了先来先服务（FCFS）调度算法
- 实现了优先级调度算法
- 支持执行日志的保存和重放

## 系统架构

### 数据结构
- **Partition**: 描述内存分区信息
- **MemoryManager**: 内存管理器
- **PCB (Process Control Block)**: 进程控制块
- **ProcessManager**: 进程管理器
- **Scheduler**: 调度器

### 主要模块
- `memory_manager.*`: 内存管理功能
- `process_manager.*`: 进程管理功能
- `scheduler.*`: 调度算法实现
- `main.c`: 用户界面和系统演示

## 编译和运行

```bash
# 编译项目
make

# 运行程序
./multi_process_scheduler

# 清理编译文件
make clean
```

## 使用说明

运行程序后，会出现以下菜单选项：

1. **显示内存状态** - 查看当前内存分区分配情况
2. **显示进程状态** - 查看所有进程的状态信息
3. **自动创建进程** - 随机生成指定数量的进程
4. **手动创建进程** - 手动输入进程参数创建进程
5. **执行时间片轮转调度** - 使用RR算法调度进程
6. **执行先来先服务调度** - 使用FCFS算法调度进程
7. **执行优先级调度** - 使用优先级算法调度进程
8. **保存执行日志** - 将当前执行状态保存到文件
9. **读取并重放执行日志** - 从文件读取并重放执行过程
10. **紧凑内存** - 执行内存紧凑算法

## 系统特性

- **时间流逝模拟** - 每次按键代表一个时间单位的流逝
- **内存管理** - 实现了固定分区的分配与回收机制
- **进程调度** - 支持多种调度算法
- **状态显示** - 实时显示内存和进程状态
- **日志记录** - 支持执行过程的记录和重放

## 设计说明

本系统遵循操作系统内核设计原则，将功能模块化设计：
- 存储管理模块负责内存的分配与回收
- 进程管理模块负责进程的创建和状态管理
- 调度模块负责CPU资源的分配和进程调度

系统采用字符界面，便于观察系统运行状态和关键数据结构的内容。
